### 1. Comparação das arquiteturas

A arquitetura Console/CLI permite que o usuário utilize o sistema por meio de comandos e menus de texto. É simples, leve e rápida de desenvolver.

A arquitetura Web funciona por meio de navegadores e servidores, permitindo acesso remoto e simultâneo de vários usuários.

A arquitetura Desktop utiliza uma interface gráfica instalada diretamente no computador, oferecendo uma experiência visual mais intuitiva, mas exigindo mais tempo de desenvolvimento.

### 2. Justificativa da escolha do Python CLI

Para o projeto TechFlow Core, a arquitetura CLI foi escolhida porque o objetivo principal é desenvolver um sistema de gerenciamento de demandas. Com ela, será possível cadastrar, listar, buscar, atualizar e excluir informações sem precisar desenvolver uma interface gráfica complexa.

Além disso, o Python oferece recursos suficientes para implementar as funcionalidades necessárias, facilitando o desenvolvimento e a manutenção do sistema.

### 3. Conclusão técnica

A escolha da arquitetura CLI é justificada pela simplicidade, facilidade de manutenção, baixo consumo de recursos e rapidez no desenvolvimento. Ela permite concentrar os esforços na lógica de programação e na organização dos dados. Futuramente, o sistema poderá evoluir para uma aplicação Web ou Desktop, caso surjam novas necessidades.

---

### 4. Defesa técnica – Comitê de Arquitetura

**Pergunta 1: Por que você escolheu Python com arquitetura CLI em vez de começar diretamente com uma aplicação Web?**

**Resposta:** Escolhi Python com arquitetura CLI porque é uma opção mais simples, rápida e leve para desenvolver o projeto. Assim, posso focar nas funcionalidades principais, como cadastrar, listar, buscar, atualizar e excluir demandas, sem precisar desenvolver inicialmente uma interface gráfica ou servidor Web.

**Pergunta 2: A arquitetura CLI poderá atender às necessidades futuras do TechFlow Core?**

**Resposta:** Sim. Inicialmente, a CLI atende às necessidades do projeto, mas, se o sistema crescer e precisar atender vários usuários simultaneamente, poderá evoluir para uma aplicação Web, aproveitando a lógica de programação já desenvolvida.

---

### 5. Resultado esperado

O projeto TechFlow Core utilizará Python com arquitetura CLI, priorizando simplicidade, organização, desempenho e facilidade de manutenção.

**Conclusão:** A arquitetura escolhida atende aos requisitos iniciais do projeto e permite futuras melhorias.
